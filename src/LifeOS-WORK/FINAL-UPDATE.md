# LifeOS Premium Update

This build keeps the existing Dashboard, Tasks, Goals, and Habits treatment intact and upgrades the remaining sections:

- Study: premium dashboard, add/edit/delete subjects, progress editor, focus controls.
- Finance: premium dashboard, add/edit/delete expenses, edit amount/name.
- Notes: premium second-brain layout, add/edit/delete notes.
- Calendar: premium weekly layout with clean event cards, add/delete events, accent colors.
- Focus Timer: start, pause, reset; available from Dashboard and Study.
- Auth: premium login/signup experience with password visibility toggle and clear states.
- Theme: existing dark/light toggle retained; new sections use the same theme variables.

Supabase credentials remain external via `.env.local`.
